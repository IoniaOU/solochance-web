Awesome Experimental Pools from SoloChance.org

Pools built and hosted by SoloChance.org with unique payment schemes that break from the traditional "whole block to one winner" model — designed to give small-hashrate miners more frequent, meaningful outcomes instead of near-zero odds.

Pool Description
solo100.org
The first pool to gamify Bitcoin mining. It invented stratum gaming: the top 100 addresses ranked by share score each receive an equal cut of the block reward, turning solo mining from an all-or-nothing bet into a leaderboard you can actually climb with a small miner like a Bitaxe. Visit →
bch.ee
A Bitcoin Cash port of Bitcoin Parasite Pool — the block finder gets 1 BCH, and the rest is shared proportionally by contribution. The first block was found on August 9, 2026 at 23:18:42, as block #963375. Blocks are very frequent — visit the Found Blocks page. Visit →
bitcoincash.ee
Brand new — the world's second Stratum game after solo100.org, and the world's first Bitcoin Cash mining meta-game. The block finder gets a 1 BCH bonus, and the remaining reward is split among the round's Best 13 shares (38.3% / 23.6% / 14.6%, then 2.35% each for 4th–13th). The first block was found on August 26, 2026 at 14:21:37, as block #965765 — visit the Found Blocks page. Visit →

The Classic Experience

Established, trusted pools with a proven track record of found blocks — from strict solo to the newer Parasite scheme. For miners who want reliable, time-tested options with almost no risk.

Pool Description
ckpool.org
The Prometheus of solo Bitcoin mining, built by Con Kolivas — who also created cgminer. The ckpool and cgminer duo have shaped the foundation of Bitcoin mining as we know it. Visit →
publicpool.io
Open-source, zero-fee solo Bitcoin mining pool — find a block and keep 100% of the reward. Self-hostable for full sovereignty, or use the hosted version at web.public-pool.io. Visit →
atlaspool.io
A globally deployed solo Bitcoin mining pool with a 1.5% fee. Uses BGP Anycast across 9 worldwide endpoints to automatically route miners to the closest server for minimum latency. Visit →
parasite.space
Block finder earns 1 BTC outright — the rest is shared proportionally with all miners since the last block. Zero fees, Lightning Network payouts, and a 10-sat withdrawal minimum. Built for home miners under the motto "Plebs eat first." Visit →
sololuck.io
A 0% fee true-solo pool running in more than one region — Bitcoin nodes in Jakarta and Phoenix, plus a Singapore door — where the finder keeps the entire block reward, with no account and no KYC. Four difficulty tiers with real per-port floors, down to difficulty 1 on the Nano port, so NerdMiner and CPU-class hardware is served rather than turned away. Visit →
